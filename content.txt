===============================
DIRECTOR'S NOTES - ОБЩАЯ РЕЖИССУРА
===============================

ОБЩИЕ ПРИНЦИПЫ АНИМАЦИИ:
- Все анимации должны быть subtle и не раздражающие
- Используйте ease-in-out transitions (не linear)
- Scroll-triggered animations появляются когда элемент на 20% виден
- Максимальная длительность анимации: 0.6s для больших элементов, 0.3s для мелких
- Prefers-reduced-motion: отключайте анимации для accessibility

ИНТЕРАКТИВНОСТЬ:
- Все CTA кнопки: hover scale 1.05, shadow increase, 0.2s transition
- Карточки: hover lift (translateY -5px) + shadow
- Формы: focus состояния с border-color transition
- Микро-интеракции везде где возможно (но не перебор)

ЦВЕТОВАЯ СХЕМА:
- Светлая тема по умолчанию
- Тёмная тема опционально (toggle в nav)
- Акцентный цвет: выберите один яркий (синий/зелёный/фиолетовый)
- Градиенты: используйте для hero и CTA секций

ТИПОГРАФИКА:
- Заголовки: жирные, крупные, короткие
- Тело: комфортный размер для чтения (16-18px)
- Line-height: 1.6-1.8 для читаемости
- Max-width для текста: 65-75 символов

АДАПТИВНОСТЬ:
- Mobile-first подход
- Breakpoints: 640px (mobile), 768px (tablet), 1024px (desktop), 1280px (xl)
- Touch-friendly кнопки на мобильных (min 44x44px)
- Swipe gestures где уместно (pricing cards, testimonials)

ПРОИЗВОДИТЕЛЬНОСТЬ:
- Lazy loading для изображений
- Defer non-critical JS
- Минимизировать animations на mobile для battery
- Использовать CSS transforms вместо position для анимаций

ЧЕСТНОСТЬ В ДИЗАЙНЕ:
- Disclaimer для всех статистик должен быть видимым
- "Beta" badges где уместно
- Нет fake countdown таймеров
- Реальные testimonials с пометками verified/not verified
- Скриншоты из реального продукта (не mockups если можно)

ПРИЗЫВ К ДЕЙСТВИЮ:
- Основной CTA: WhatsApp (зелёная кнопка с иконкой)
- Вторичный CTA: "See Demo" или "Learn More"
- CTA повторяется каждые 2-3 секции
- Sticky CTA bar опционально на mobile при скролле вниз

ЭМОЦИОНАЛЬНЫЙ ТОНУС:
- Честный и прямой
- Немного дерзкий (challenge status quo)
- Эмпатичный (понимаем боль)
- Оптимистичный но реалистичный
- Без corporate BS

===============================
ТЕХНИЧЕСКИЕ ДЕТАЛИ ДЛЯ РАЗРАБОТКИ
===============================

СТРУКТУРА ФАЙЛА:
- Single HTML file как запрошено
- Встроенный CSS в <style> блоке
- Встроенный JS в <script> блоке (или ссылка на CDN для библиотек)
- Все ассеты инлайн или CDN (никаких локальных файлов)

РЕКОМЕНДУЕМЫЕ БИБЛИОТЕКИ:
- AOS (Animate On Scroll): https://michalsnik.github.io/aos/
- Vanilla JS для интерактивности (можно Alpine.js для реактивности)
- Tailwind CSS CDN для быстрой стилизации (опционально)
- Font: Inter или Manrope из Google Fonts

ЯЗЫКОВОЕ ПЕРЕКЛЮЧЕНИЕ:
